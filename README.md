# google_forms_survey_automation
This code generates three google forms with links for AI-TPACK Study
It builds a research survey in Google Forms from one script; Participant demographics, Likert scales, tool inventory, and rater rubric
This automation was developed because manual form construction was time-consuming and prone to errors, which required repeated editing and increased the risk of data-quality problems.
Paste the script generated into script.google.com., then run createAllforms.
The Google Apps Script was used to generate the survey forms.
The skills demonstrated in this project were the survey design, automation, SPSS-ready variable coding (ATI1, DL5, etc)
The final output is three Google Forms containing 60 survey items, generated in under one minute.
